S19.3 — Reading measure and sticky header

At wide desktop widths, article Markdown renders in a centered 70ch grid track. The header stays sticky; TOC and hash targets use a shared block size for scroll offsets.

Functional requirements

Normal direct children occupy the middle track. Top-level tables and code blocks span the full article column without breaking measure.

Grid behavior

The three-column grid activates at 1200px to avoid conflict with the floated infobox at tablet widths.

Do not reintroduce per-child width/auto-margin — it fragmented article layout in earlier iterations.

Acceptance criteria

Given a generated article at 1280px, when the user scrolls to an h2 anchor, then the heading clears the sticky header without overlap.

Contents

Functional requirements Grid behavior Acceptance criteria
  • Helvetica body; browser-default heading sizes on 14px root
  • Headings sans-only — no serif distinction for page title
  • Menlo-first monospace (differs from BRAND wordmark stack)
